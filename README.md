# シバラン 〜シャンプーいやや〜

シャンプーを嫌がる柴犬が、シャワーを持った飼い主から逃げ回るスマホ向けエンドレスランナー。
three.js（3D描画）+ Canvas 2D（HUD）+ TypeScript + Vite。今は図形だけの仮グラフィック。

公開URL（GitHub Pages）: https://yasufabric.github.io/shiba-run/

## 起動

```bash
npm install
npm run dev
```

- PC: http://localhost:5173
- スマホ: PCと同じWi-Fiにつないで、`npm run dev` のターミナルに出る `Network: http://<IP>:5173` を開く

ビルド: `npm run build`（`dist/` に出力）／確認: `npm run preview`

## GitHub Pages で公開

`main` に push すると `.github/workflows/deploy.yml` がビルドして GitHub Pages にデプロイする（PR ではビルド確認のみ）。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしておく。

## 操作

| 操作 | スマホ | キーボード |
| --- | --- | --- |
| レーン移動 | 左右スワイプ | ← → / A D |
| ジャンプ | 上スワイプ / タップ | ↑ / W / Space |
| 柴ドリル | 下スワイプ / 右下ボタン | ↓ / S / Shift |
| 音のオン/オフ | 右上のスピーカーボタン | M |

## ルール

- 飼い主が後ろから追ってくる。画面上部の「飼い主との距離」が 0 になったら捕まってゲームオーバー
- 飼い主は少しずつ速くなる。ぶつかったり濡れたりすると、さらに距離を詰められる
- スコア = 走行距離 (m) + ボーナス

| もの | 効果 |
| --- | --- |
| バケツ | ぶつかると転んで大減速（ジャンプで跳び越えられる） |
| 石けん | 踏むと隣のレーンに滑り、少しの間操作できない |
| タオル（タオル掛け） | ぶつかると頭にかぶって前が見えなくなる |
| 焼きいも | 3秒間の猛ダッシュ＋無敵。障害物を蹴散らせる |
| ささみ（骨付き肉） | ボーナス +50。貯めると新しい柴を解放できる |
| シャワー | 飼い主が狙ったレーンに発射。当たるとびしょ濡れで減速＆距離が縮む |
| 大波 (25秒〜) | 3レーン全部を覆う。柴ドリルでしか防げない |

BGMは最初にタップした時点で鳴り始める（ブラウザの仕様）。iPhone はマナーモードだと音が出ない。

**柴の着せかえ**: 拾ったささみは貯まっていく。タイトル画面の ◀ ▶ で柴を選び、ささみで 黒柴（20）・白柴（50）・胡麻柴（100）を解放できる。進行状況はブラウザに保存される。

**結果のシェア**: ゲームオーバー画面の「結果をシェア」で、スマホは共有シート（スクショ画像つき）、PC は X の投稿画面を開く。

**柴ドリル**: ブルブル回転して近くの水しぶきを弾く。濡れ状態も解除できる。クールダウン 4 秒。

## 構成

```
src/
  config.ts   調整用パラメータ（速度・クールダウン・ペナルティなど）
  game.ts     ゲームロジック（状態・出現・当たり判定）
  world.ts    three.js による3D描画（柴・飼い主・障害物・水しぶき）
  audio.ts    Web Audio API で合成するBGMと効果音（音声ファイルなし）
  progress.ts 柴の毛色の定義と、ささみ・解放状況の保存
  hud.ts      Canvas 2D の HUD（スコア・距離ゲージ・ドリルボタン・タイトル/リザルト）
  input.ts    スワイプ／タップ／キーボード入力
  main.ts     初期化・リサイズ・ゲームループ
```

難易度の調整は `src/config.ts` の値をいじるだけでできる。
